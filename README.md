## $30、$100、$300 之间差的是什么

标准版 SuperGrok 覆盖了绝大多数人的实际需求：DeepSearch、语音、图像和视频生成、更高的整体额度。付费档位之间共享同一个每周使用池，聊天、Imagine、语音、Build 都从里面扣，这也是为什么重度使用视频生成的人特别容易撞到上限。

## 为什么你的账单不是 30 美元

官方标价是美元口径，真正扣款时会跑出几个差额：

**汇率和税费。** 非美国地区按当地货币折算，再叠加税费，同一档位在不同地方差出一半不奇怪。按写这篇时常见的折算估算，英国约 23.7 英镑、德国约 27.6 欧元、日本约 4,560 日元、澳大利亚约 45.5 澳元——这些是汇率加税费推出来的数字，不是官方的本地定价。

**应用内购。** 通过手机 App 订阅时，价格由应用商店的定价体系决定，通常高于官网。有第三方应用数据监测显示，部分地区 SuperGrok 月订的标价被记到了 40 美元。同样的服务，从网页端订阅往往更便宜。

**年付摊薄。** 300 美元一年相当于每月 25 美元，比月付省 60 美元。如果你已经确定要用满一年，月付没有意义。

**首期促销。** 偶尔会有首期折扣，力度看起来很大，但只作用在第一期。看到"99 美元"这类数字时，先确认后面恢复成多少，别把促销价当常态价。
